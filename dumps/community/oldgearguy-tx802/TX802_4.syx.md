Labelled for the ReMOTE **ZeRO** SL (Mk1). The ZeRO SL is the keyless sibling of the SL Mk1 and its template message is byte-identical in layout (same header F0 00 20 29 02 03 7F, same 4112-byte length, same 90x41 records), so it is kept with the Mk1 dumps. The author notes these templates use a device feature the Template Editor rejects: drum pads of type TEMPLATE that also carry a SysEx payload. See `README.txt` and `TX-802_Mapping.xls` (physical layout, used to confirm record order).
